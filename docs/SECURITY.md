# 安全说明

本插件运行在宿主进程内，只动自己的目录。这里说明它碰什么、不碰什么。

- 插件**不含任何凭据**，运行时从 Harness 自己的凭据文件读取
- 从不打印或返回 token
- 只读取会话日志，不修改
- 除「注入人设」「主动推送」「查余额」外无其它网络请求
- `/search` 只把查询词发给宿主的 web 搜索服务；`/share` 只在 127.0.0.1 起一个下载服务

## `/share` 的安全边界

- 下载令牌是 `randomBytes(32)`（256 位熵），与文件路径、内容、时间无关，**不可枚举、不可反推**
- 一条分享只对应命令行指定的一个文件；未知令牌一律 404
- 默认 30 分钟过期 + 3 次下载上限，到期/用尽自动删除
- daemon 只监听 `127.0.0.1`，外部访问必须经过你自己的 HTTPS 反代
- 只接受 `GET` / `HEAD`，不列目录；访问日志不记录令牌全文
