# 命令详解

> 命令清单（速查表）在 README；这页讲每条命令的具体用法、输出样例和边界。
> 命令全部由**宿主进程**执行，不经过模型，因此不消耗 token、响应即时。

## 通用说明

> **关于 token 相关命令**：`/token` 会优先查官方用量与余额，需要你在
> `$DSH_HOME/.credentials.yaml` 里提供 `DEEPSEEK_USER_TOKEN`（可选）。
> **首次使用不强制绑定**——没配也能用，只是退化成「仅本地统计」，命令会明确提示。

## 用量与余额

### 用量与余额

> **可选的官方数据**：官方用量/余额查询需要 `DEEPSEEK_USER_TOKEN`（放在
> `$DSH_HOME/.credentials.yaml` 里，602/600 权限）。**不绑定也能用**——
> `/token` 会退化成「仅本地统计」并在输出里明确标注；绑不绑由你决定，本插件不会强求。


```
你：/token

【本次会话】
  请求 12 次 / 轮次 5
  输入 12,345（缓存 6,789 / 新增 5,556）
  输出 678（其中推理 123）
  合计 13,023 · 缓存命中率 55.0%
  估算花费 $0.0012

【今日累计】3 个会话
  输入 1,234,567（缓存 1,111,111 / 新增 123,456）
  输出 8,901（其中推理 4,567）
  合计 1,243,468 · 缓存命中率 90.0%
  估算花费 $0.02（按 v4-flash 价目，USD）

【账户余额】
  可用 ¥100.00（CNY）
  充值 ¥100.00 / 赠送 ¥0.00
  账户状态：正常

（以上为示例数据）
```

余额来自 `GET https://api.deepseek.com/user/balance`（只读，不消耗 token）。
花费是**估算**，价目取自 pi-ai 内置的 `deepseek-v4-flash` 目录。

## 历史对话

### 历史对话

```
你：/sessions
🤖：最近的对话（共 3 个，显示最新 3 个）

    [1] 项目讨论 ← 当前
         刚刚 · 22 条提问
    [2] 定时问候配置
         2 小时前 · 8 条提问

    用 /load <编号> 把该对话的上下文载入当前会话。
```

**`/load` 是「载入上下文」，不是「切换会话」** —— 会话 id 不变，只是把旧对话内容注入进来。
想干净开局就 `/new` 后再 `/load`。

真切换的实现原理与风险控制见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md#七真会话切换怎么做120-起支持)。

## 深度调研搜索

```
/search <关键词>           标准调研：3 轮查询 + 抓正文 + 事实概述
/search <关键词> deep      超深度：模型判时效 + 中英混合规划 + 从结果抽关键词补搜一层（≤2 层）
/search <关键词> brief     只给找到的资料，不做概述
/search <关键词> en        英文关键词
```

输出结构：概述 → 分界线 → 参考来源（带日期）。`deep` 会按 `1d/3d/7d/30d/any` 判断时效窗口，
窗口内资料不足时按 `1d→3d→7d→30d` 逐级放宽（纯本地筛选，不重搜）；概述与参考来源永远共用同一批资料。

底层复用宿主服务：`ctx.web.search` / `ctx.web.fetch` / `ctx.llm.stream`。

## 临时下载链接

```
/share <文件>              分享（默认 30 分钟 / 3 次）
/share <文件> 120 5        自定义：120 分钟 / 5 次
/share list                看进行中的分享
/share stop <id|all>       立刻失效
/share status              服务状态
```

链接形如 `https://<你的域名>/s/<令牌>/<文件名>`。令牌 256 位随机，猜不到；到期或用尽即失效。
对外前缀由 `SHARE_PUBLIC_BASE` 决定，不配则只有本机能打开。
安装、Caddy/Nginx 配置与排障 → [SHARE.md](SHARE.md)

## 从菜单里隐藏别的插件的命令

### 从菜单里隐藏别的插件的命令

同一宿主上如果还有**其它插件**注册了斜杠命令，`/help` 会把它们归进「扩展命令」组。
不想让它们出现在菜单里（比如只对你自己有意义的那几条），就在
`~/.dsh/.whale-commands/hidden.commands` 里一行写一个命令名：

```
# 注释行
example-a
example-b
```

- **只影响菜单展示，命令本身照常可用**
- 文件不存在＝不过滤；读不到也当空集，不影响启动
- 这份名单只在本机状态目录里，不属于仓库；插件代码里不含任何具体命令名
