## 两个入口，分工不同

| 命令 | 定位 | 说明 |
|:--|:--|:--|
| `/persona` | **人设库主入口** | 列表 / `3` / `maid` / `off`，11 套全在这里切 |
| `/whale` | **鲸鱼娘专属纪念命令** | 保留的原始入口，**一字未改**——切回最开始的「鲸鱼娘·大肥鱼」 |
| `/normal` | 关闭人设 | 恢复普通口吻（等价 `/persona off`） |

> `/whale` 与 `/normal` 是**为纪念保留**的：插件最早只有「鲸鱼娘开关」一个功能，
> 后来才扩成人设库。这两个入口保持原样，老用法和脚本不用改。

## 用法

```
你：/persona            ← 列出全部人设（编号 + 简介）
你：/persona 3          ← 切到第 3 套
你：/persona maid       ← 也可用 id 切
你：/persona off        ← 关掉，恢复普通口吻
你：/whale               ← 纪念版入口：切回鲸鱼娘·大肥鱼
你：/normal             ← 关闭人设
```

## 粘性与作用范围

- **人设是「粘住」的**：开启后，之后每个 `/new` 出来的微信会话都会自动继承；关闭用 `/persona off`（或 `/normal`）。
- 只对**微信会话**生效（按 `weixin-` 前缀过滤），Web GUI 里的会话不会被人设影响。
- 换人设后，`/style auto` 的早间问候也会跟着换口吻 → 见 [GREETINGS.md](GREETINGS.md)。

## 改文案

人设文案与列表都在 `src/personas.mjs`（公开版共 11 套，含每套的早间问候文案）。
改完跑一次 `sync-version.sh` 即热生效 —— 详见 [DEVELOPING.md](DEVELOPING.md)。
